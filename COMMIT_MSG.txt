Handbill Browse cards, Performer page rebuild, MusicBrainz + Commons

Browse cards
- Replace the waveform strip with a handbill card: gig-poster typography
  rendered from the show's own metadata. Waveform-led cards are what the
  Internet Archive's Live Music Archive already does. Metadata is also the
  better-covered asset — every performance has a year and 542/544 a city,
  against 530 with waveform data and 118 with a letter grade.
- Date renders at full weight: for a live recording the date IS the identity.
- Handbill is Recommended-only; Recently Added gets its own row-card layout
  carrying the ingest date, ordered created_at DESC.
- Card colour comes from the performer's GENRE, not source. New genre.color
  with a picker in the Genre editor; NULL renders neutral grey.
- Browse endpoints no longer request `waveform`; recording_row(waveform=) and
  downsample_peaks() stay intact and tested, and a test now asserts the
  waveform's ABSENCE (the opt-in eager-loads every track's analysis row).

Performer page
- Rebuilt as hero + tabs (Overview / Recordings / Photos). Members move above
  Description and list one per row with tenure visible — the stint editor was
  previously undiscoverable.
- AI Assist moves onto the Description header and now OVERWRITES the bio. First
  exception to "AI suggests, human approves"; a biography is visible on landing,
  freely editable, and nothing computes from it.
- Strip citation markup server-side in performer_research.py so what's stored
  is clean, not scrubbed at render time.
- Resources reframed as "Trusted sources" — act-specific sites used as sources
  of truth by future enrichment jobs.

MusicBrainz (new)
- app/utils/musicbrainz.py + real columns on performer, indexed mbid.
- Runs at Performer creation on both the ingest and manual paths.
- Never auto-picks: requires top score >=88 AND a >=12 margin, because a 100
  with a 98 behind it is ambiguous however high the top looks. The manual
  lookup does link when that gate is satisfied.
- 'matched' vs 'linked' are distinct so the page can say "Matched
  automatically" or "Linked by you" accurately.
- Members are read-only. MB membership maps onto our stints, which is exactly
  why it must not write — roster changes cascade into per-show personnel.
- Disabled under TESTING; circuit breaker after 3 failures so an offline bulk
  import can't spend minutes on DNS timeouts.

Wikimedia Commons photos (new)
- performer_image table: many per act, one primary, origin + source_ref +
  credit. Replaces the single image_ext slot (left in place, unread).
- Photo fetch via Wikidata P18 -> Commons. Commons only, never Wikipedia's
  local file namespace, which hosts non-free "fair use" images that look
  identical in a scrape. Unreadable licence = refused, never stored with a
  guess.
- Repeat fetches skip filenames already imported.

Backfills + shared code
- backfill_recording_quality.py: librosa analysis and listening quality in one
  walk of the library (both decode the same audio).
- backfill_musicbrainz.py, backfill_performer_photos.py. All resumable.
- Extract analyse/version-check/upsert into app/utils/analysis.py — it existed
  in three copies and spectral_cutoff_hz was one schema change from diverging.
- estimate_cost_cents(): pre-flight cost RANGE, not a figure.
