Ingest defaults to Move; create forms; card initials; ingest recovery

Ingest file handling now defaults to MOVE
- Copy left the show sitting in the import folder, so a later re-scan offered
  the same recording again and a second ingest was one click away. That is
  where the duplicates came from. Move makes re-ingesting the same files
  structurally impossible.
- Changed in all three places a default was resolved: the server preference
  fallback, the ingest confirm fallback, and the frontend's own defaults.
  Move is now listed first in every file-handling select.

Fatal: stranded after ingesting an act's last recording
- Ingesting the final show of an act moves its folder into the library, and the
  empty-parent cleanup then removes the act folder. Returning to Add Recording
  tried to re-open that path and rendered a bare error with NO ACTION — the
  error was right, having no way out was the bug.
- _ingestRenderFailed now offers Start over / Go to Library, and clears the
  remembered folderPath, which is what re-broke the page on every retry.
- Entering the review step without a scan falls back to the picker instead of
  throwing.
- runScan no longer returns silently when #scan-status is absent, and clears
  the stale path on failure.
- /api/quality/browse climbs to the nearest surviving ancestor rather than
  returning 400, re-checking IMPORT_ROOTS after the climb, and reports
  redirected_from so the picker can explain the jump.

Create forms
- New shared renderCreateForm(), used for New venue / performer / artist. The +
  buttons previously did two different wrong things: Venues navigated to the
  admin LIST (a view-and-edit screen, not a create flow), and performers and
  artists used window.prompt(). Removes _promptCreate().
- Route ordering matters here: the /new routes must precede the
  '#/<thing>/<id>' prefix matches or '#/artist/new' parses as id NaN.

Avatars
- Performer cards render an INITIALS disc when there is no photo, matching the
  entity-page hero. Previously they rendered nothing, so photographed and
  un-photographed acts produced two different card shapes — and since most
  acts have no photo, the empty one was the common case.
- Venue portraits and gallery tiles are square, so a place never reads as a
  person.

Venue page
- Tab moves City -> State/Region -> Country -> Notes, and Shift-Tab back.
  makeInlineEditable gained an optional tabTo hook; it commits, then clicks the
  next element, reusing the one path that opens an editor.
